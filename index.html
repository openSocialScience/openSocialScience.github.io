支持的 AI 助手

OpenSocialScience 以技能包的形式安装到 AI 助手中。在对话框中输入研究方向，即可启动完整流程。

程序负责计算和核对，模型负责判断

可以机械核对的内容，系统会在流程中逐项检查。
下面介绍其中三项。

正文数字由程序填入

写作阶段，正文中的统计结果用引用标记表示，例如 {{result:main.coef}}。生成终稿时，程序从结果文件读取数值并填入。正文中出现手动输入的数字时，检查不通过。

复现步骤
出身效应的估计值为 0.188。
检查结果：第 13 行有手动输入的数字 0.188
驳回
出身效应的估计值为 {{result:main.coef}}。
生成终稿：出身效应的估计值为 0.188。
通过

由另一家模型审稿

论文初稿交给另一家厂商的模型审稿，作为独立验证。使用同一厂商的模型时，论文的局限部分会注明。

设计说明
写作模型claude-opus-4
审稿模型claude-sonnet-4同厂商审稿
审稿模型deepseek-chat跨模型审稿
初审→三位审稿人→主编意见→修改后复审

每个环节都有检查

例如统计功效不足时，流程停在可行性检验；分析计划引用了数据中没有的变量时，流程无法继续。这些检查由程序执行。

诊断给出的每条建议都要处理：采纳，说明理由后不采纳，或写入论文局限。全部处理完才能导出。

完整检查清单
  • 有效样本量：10 391 行折算为 1 612已计入
  • 估计精度：95% 置信区间半宽约 0.095，处在灰区正文说明
  • 分组变量 urban_hukou3 与 urban_hukou 存在嵌套已说明
  • 两项稳健性检验与主结果方向相反正文改写
  • 导出 paper.docx审稿后导出

11 种估计方法

固定效应、双重差分、事件研究、工具变量、断点回归、多层模型等，每种都附带相应的诊断，支持抽样权重和复杂抽样设计。

内置数据集

QoG、V-Dem、GSS、CGSS 等数据集可以直接调用，并附带出处和引用格式。世界银行、OECD 等来源也可以按指标获取。

期刊格式

内置《社会学研究》《管理世界》《中国社会科学》和 Social Forces 的格式，也可以自定义。

多智能体仿真

没有现成数据时，可以运行多智能体仿真生成数据，再进入同样的研究流程。支持 OASIS 和 AgentSociety。

安装

可以让 AI 助手代为安装：在 Claude Code、Codex 等助手中发送下面这句话，助手会完成下载、安装和环境检查。过程中需要你提供审稿模型和文献检索服务的 API 密钥。

帮我安装 https://github.com/openSocialScience/openSocialScience ，照仓库里的 docs/INSTALL.md 做。

手动安装

1安装

需要 Python 3.11 及以上版本，以及用于导出 Word 文档的 pandoc。

git clone https://github.com/openSocialScience/openSocialScience
cd openSocialScience
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev,figures,stats-formats,excel,causal,reading]"

2配置

在项目根目录创建 .env 文件，填写审稿模型和文献检索的密钥。审稿模型可使用任何兼容 OpenAI 接口的服务，建议与 AI 助手来自不同厂商。完成后运行 oss doctor 检查环境，再用 oss install-skills 安装到助手中。

REVIEWER_BASE_URL=https://api.deepseek.com/v1
REVIEWER_MODEL=deepseek-chat
REVIEWER_API_KEY=sk-...
EXECUTOR_MODEL=claude-opus-4
OPENALEX_API_KEY=...

oss doctor
oss install-skills

3运行

在 AI 助手中输入命令，提供研究方向、数据和学科即可开始。其他可选参数可以用下方的提示词生成器填写。

/social-research 你的研究方向 --- data: 你的数据.csv --- discipline: sociology

提示词生成器

按需填写下列参数，完整命令会随填写实时生成，复制后粘贴到 AI 助手的对话框即可。未填写的参数使用默认值，必填项缺失时系统会在运行开始后询问。

用一句话描述研究问题。
数据文件路径或内置数据集名称（如 pack:qog），多个用逗号分隔。使用仿真数据时填 sim:<名称>。
不同学科对因果推断的要求不同，此项影响审稿标准和选题角度。
只影响论文语言，文献检索始终包括中英文文献。
指定后，研究类型在后续流程中保持不变，只允许从因果调整为描述。
填写后系统不再另行选题，而是把你的想法整理为研究方案，并照常进行评审和可行性检验。原文完整保留，作为后续研究的依据。
design:计量设计
已确定计量设计时填写，可只填部分，其余由系统补全；全部留空则由系统在制定分析计划时决定。
支持 RIS、EndNote、RefWorks、NoteExpress 题录文件，单篇 PDF 或 PDF 文件夹，多个用逗号分隔。知网、万方的文献需要通过这种方式导入。
目标期刊的格式模板。仓库内置四种，也可以自行添加。
checkpoint:停下来让你看
默认不暂停，流程一次运行完成。

适用场景

        
    
          
  • 个体层面的调查数据，如 CGSS、CFPS、GSS、WVS
    • 
          
  • 国家层面的年度数据，如 QoG、V-Dem、世界银行数据
    • 
          
  • 需要结果可追溯、可复核的研究
    • 
          
  • 数据层级应与研究问题一致，例如国家层面的数据不适合回答个体层面的问题
    • 
        

      

      

        
暂不支持

        
    
          
  • 质性研究，如民族志、深度访谈、扎根理论
    • 
          
  • LaTeX、幻灯片和海报格式（目前仅输出 Word）
    • 
          
  • 专著的全文检索
    • 
          
  • 需要申请使用权限的数据集无法自动获取，系统会提供申请方式和存放位置
